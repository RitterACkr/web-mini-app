# OSとは

> **OSとは「ハードウェアとアプリの間に立つ存在**

例えばブラウザを開くとき，裏でOSは:
- CPUの時間をブラウザに割り当て
- メモリの空き領域を確保して渡し
- キーボード入力をブラウザに届ける

...などが行われている

## OSがないと何が困る?

例えばOSなしで複数のアプリを動かそうとした場合
```
アプリA: 「メモリのアドレス100番に書き込みます」
アプリB: 「アドレス100番はうちが使います！」
→ 衝突
```
といった事態が起こる可能性がある

OSが間に入ることで:
- 各アプリには「自分専用のメモリ空間がある」ように見せかけられる
- CPUを順番につかいまわせる
- 暴走が起こった場合でも，他アプリを守ることができる

## mini-osで学ぶこと

このシミュレータでは OSの3機能を体験できる予定です

| 機能                | mini-osでの表現                     |
| ------------------- | ---------------------------------- |
| **プロセス管理**     | プロセスの生成・状態変化を観察        |
| **スケジューリング** | どのプロセスがいつCPUを使うかを可視化  |
| **メモリ管理**       | 限られたメモリをどう分配するかを可視化 |
