# プロセスとは

## プログラムとプロセスの違い

|         | プログラム          | プロセス               |
|---------|--------------------|-----------------------|
| 実体    | ディスク上のファイル | メモリ上で動いているもの |
| 複数起動 | 1つのファイル       | 複数のプロセスになれる  |

例: Chromeを3つのウィンドウで開いた場合: <br>
⇒ 同じプログラムから **3つのプロセス** が生まれる

## プロセスの状態

プロセスはOSによって以下の5つの状態を行き来する:
```
    　生成
      ↓
    [ New ]
      ↓ OSに受理される
    [ Ready ] ←─────────────┐
      ↓ CPUを割り当てられる   │
    [ Running ]             │ タイムスライス切れ/高優先度が来た
      ↓ I/O待ちなど          │  
    [ Waiting ]─────────────┘
      ↓ 完了
    [ Terminated ]
```

### 各状態の意味

**New (新規)** <br>
プロセスが作られたばかりの状態. またCPUを使う準備はできていない

**Ready (実行可能)** <br>
CPUが空けばすぐに動ける待機状態. 複数のプロセスがここで並ぶ

**Running (実行中)** <br>
CPUを使って実際に命令を実行している状態. 
例えばシングルコアなら同時に1プロセスだけ

**Waiting (待機中)** <br>
ファイル読み込みや入力待ちなど, CPU以外のリソースを待っている状態.
CPUを手放して他のプロセスに譲る.

**Terminated (終了)** <br>
処理が完了した状態. 使っていたメモリなどを解放.

## PCB (Process Control Block)

OSはプロセスを管理するために **PCB** というデータをプロセスごとに持つ.
```
PCB for P1:
  pid:          1
  name:         "P1"
  state:        Running
  priority:     5
  burstRemain:  6  ← あと6クロック分CPUが必要
  memStart:     20 ← メモリの20番地から確保中...
```

mini-os では `process.js` の `createProcess()` がこれを生成している.

## ターンアラウンドタイムと待ち時間

スケジューラの良し悪しを測る指標:
```
到着    初回実行   　　　　　　　　終了
  ↓        ↓        　　　　　　   ↓
──┼────────┼──────────────────────┼──→ 時間
  ├─待ち時間┤        　　　　　　　 │
  ├──── ターンアラウンドタイム ─────┤
```

- **待ち時間** → Readyキューで待っていた合計時間
- **ターンアラウンドタイム** → 到着から終了までの総時間
